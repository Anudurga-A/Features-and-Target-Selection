# Task 31: Features and Target Selection

## 📌 Objective
To understand the basic structure of supervised machine learning by selecting suitable input features and a target variable from a dataset.

## 🛠️ Tools Used
- Python
- Pandas
- Scikit-learn
- Jupyter Notebook

## 📊 Dataset
Iris Dataset

The Iris dataset contains flower measurements used to classify different species of Iris flowers.

## 🔍 Selected Features
The following input features were selected:

- Sepal Length (cm)
- Sepal Width (cm)
- Petal Length (cm)
- Petal Width (cm)

## 🎯 Target Variable
**Target:** `target`

The target variable represents the Iris flower species, encoded as numerical values.

## 💡 Explanation
The four features were selected because they provide useful measurements for identifying different Iris flower species.

The target column was selected because it represents the value that a supervised machine learning model aims to predict.

The target column is not included among the input features to avoid data leakage.

## ✅ Result
Successfully selected the input features and target variable from the Iris dataset and understood their roles in supervised machine learning.
